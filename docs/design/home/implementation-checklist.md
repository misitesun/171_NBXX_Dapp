## 页面顺序与语义

1. 公共顶部区域：品牌、LanguageSwitch、钱包信息；过滤手机状态栏。
2. Hero：h1 主标题、限量席位文案、NFT 皇冠及星球装饰。
3. NFT 选择：两枚原生 button，受控本地选择状态，以 aria-pressed 表达；初始选中高级 NFT。
4. 购买操作：button，图标与文案随选中等级更新；无接口时不进行支付、不伪报交易成功。
5. 安全/限量/股东说明：语义列表。
6. 权益对比：两栏相同权益行对应展示，使用 Grid/Flex 正常流，保留不同数值和强调色。
7. 平台指标：六张统计卡，使用两列 Grid。
8. 媒体伙伴：两行横向轨道，通过流式 Flex 与裁切容器展示。Figma 首行相对 x=-220、次行 x=-320；是否添加滚动动效不从静态画面推断。
9. 页脚：单份品牌资源、口号、官网及 X 链接、社区二维码。链接使用 a，二维码使用 img。

静态阶段 /h5 直接进入首页，钱包、签名、后端 Token 不阻断预览。设计中的钱包缩略地址不是已连接账号事实。

## 复用清单

- 组件：MainLayout、AppBrand、LanguageSwitch；购买按钮评估 ActionButton 的尺寸/边框能力，无法精确表达时使用页面语义 button；反馈复用 Toast，不自建弹窗基础设施。
- 类：flex、items-center、justify-between、justify-center、size-*、bold-* 及既有间距工具；只在与实测要求一致时复用。
- mixin：评估 gradient-card / gradient-word / hide-scrollbar；只有参数化能力与 Figma 一致才用，不套用模板紫色渐变默认值。
- 私有样式：Hero 图层、NFT 选择卡、两栏权益、平台卡、不等行距、媒体横轨裁切、二维码布局。
- theme：#010E18、#25EC77、绿操作渐变及公共文字/状态色进入 color.scss；星球图、月桂、一次性的金色光效保持页面资源和私有样式。
- 不添加无需求的 CountUp、orbit-border；媒体滚动由开发者后续明确授权，参见 interaction-update.md。
- 页面作用域复用 hide-scrollbar，避免桌面滚动条压缩设计画板宽度；仍保留原生纵向滚动。
