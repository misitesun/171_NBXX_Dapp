## 顶部映射与已知差异

公共顶部100px，设计顶部128px包含设备状态标注。H5 不渲染设备信息，也不为它保留高度。首页及品牌原始纵坐标减去28px。侧栏入口保留；真实未连接状态显示对应语言状态，未复制设计示例钱包地址。

Poppins Regular/SemiBold 来自官方 google/fonts，附 OFL 许可证。PingFang SC 依赖系统字体；不含该字体的设备使用 CSS 中文后备字体，字形无法保证与 Mac 完全一致。

媒体两条静态轨道保留原稿裁切，不添加动画。初始化正方形 Logo 和 Empty 图标仍按开发者意见跳过，不将横向字标当作完成生产品牌准备。
